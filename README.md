# Come usare e installare Diario Terapia

**Windows**: aprire `index.html` con Edge o Chrome. Funziona subito. Per installarla come app serve l'indirizzo https (vedi sotto), poi menu ⋯ → "Installa".

**iPhone e Android**: l'app va messa su un indirizzo https (gratis, per esempio trascinando la cartella `app` su https://app.netlify.com/drop oppure con GitHub Pages). Poi:
- iPhone (Safari): Condividi → "Aggiungi alla schermata Home".
- Android (Chrome): menu ⋮ → "Installa app" (o il pulsante "Installa app" in alto).

I dati restano sul dispositivo. Per spostarli su un altro dispositivo: Impostazioni → Esporta backup, poi Importa backup sull'altro.
